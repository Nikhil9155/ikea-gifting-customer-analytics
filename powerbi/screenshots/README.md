# Dashboard Screenshots

This directory contains static previews of the IKEA Gifting Customer Analytics Power BI report.

The report has two pages, with bookmark-based controls that allow users to switch between alternative analytical views.

## Overview

| File                    | Description                                           |
| ----------------------- | ----------------------------------------------------- |
| `overview_customer.png` | Customer distribution, retention, and customer trends |
| `overview_revenue.png`  | Revenue contribution by segment and revenue trends    |

## RFM Analysis

| File              | Description                                    |
| ----------------- | ---------------------------------------------- |
| `rfm_segment.png` | Segment performance and average customer value |
| `rfm_country.png` | Country performance and geographic comparisons |

## Usage

These images are static snapshots of the report. They do not provide interactive filtering or bookmark functionality.

For the full interactive experience, open [`IKEA.pbix`](../IKEA.pbix) in Power BI Desktop.
