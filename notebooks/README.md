# Python Analysis — RFM Customer Segmentation

This directory contains the Jupyter Notebook used for customer-level analysis and RFM segmentation in the IKEA Gifting Customer Analytics project.

The analysis builds on the SQL-prepared transaction data and translates purchasing behaviour into customer-level metrics and business-oriented segments.

## Analytical Workflow

### 1. Data Preparation

Load the prepared transaction data into Python and apply the eligibility filters required for customer-level analysis.

### 2. RFM Calculation

Calculate three customer metrics:

* **Recency:** Days since the customer's most recent purchase.
* **Frequency:** Number of distinct purchase transactions.
* **Monetary:** Total monetary value generated by the customer.

### 3. RFM Scoring

Assign customer scores based on their relative recency, frequency, and monetary values.

### 4. Customer Segmentation

Use the RFM scores to assign customers to business-oriented segments, including Champions, Loyal, At Risk, New, Needs Attention, and Lost.

### 5. Churn Flagging

Apply the project's fixed 90-day inactivity threshold to identify customers who meet the defined churn criterion.

The analysis supports the identification of valuable customer groups, customers with declining engagement, and opportunities for more targeted retention strategies.
