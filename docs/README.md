# Project Documentation

This directory contains the business requirements and supporting documentation for the IKEA Gifting Customer Analytics project.

## Contents

* **Business Requirements Document (BRD):** Defines the business problem, objectives, scope, stakeholder requirements, analytical definitions, deliverables, and success criteria.
* **Supporting Documentation:** Documents the analytical methodology, assumptions, data-quality considerations, and project implementation where applicable.

## Purpose

The documentation establishes the business context for the analysis and connects the technical workflow to the customer analytics and retention objectives.
